# Quaternius Modular Character Outfits - Fantasy

- Download: https://quaternius.itch.io/modular-character-outfits-fantasy
- Local Standard archive (not tracked in Git): `source/Modular-Character-Outfits-Fantasy-Standard.zip`
- License: CC0 1.0 Universal; see `public/assets/models/quaternius-outfits/License_Standard.txt` in the repository and https://creativecommons.org/publicdomain/zero/1.0/.
- The game uses male/female Peasant and Ranger glTF outfits with their adjacent buffers and textures. Ranger supplies the enemy and Boss coat silhouettes; hoods and pauldrons are selectively hidden in the renderer. The original package notes that the outfits are compatible with the Universal Base Characters kit and that only the base character head should be retained to avoid clipping.
- Enemy cloth textures are desaturated in memory and recolored per garment; the original downloaded textures remain unchanged on disk.
- Runtime copies used by the game are in `public/assets/models/quaternius-outfits/`.
- Original author: Quaternius.
